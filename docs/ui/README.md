# UI Documentation

The current UI is a minimal provider-management page (`GET /providers`) plus a
live WebSocket dashboard (`WS /ws/dashboard`) that streams every bus event.

The unified **Mission Control** web UI and the **Desktop Client** (Tauri) are
specified in [`../../MISSION_CONTROL_SPEC.md`](../../MISSION_CONTROL_SPEC.md)
and planned for Phase 3+. This directory will hold UI architecture, component
guides, and design tokens when those ship.
